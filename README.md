# manga-downloader
Закачка манги оффлайн

Утилиты:
1. Чтение мета информации (главы и ссылки на изображения для них)
2. Закачка изображений по мета информации
3. Сформировать json для веб-ридера

Использование:
1. Запустить reader-urls предварительно поправив ссылку на мангу в переменной (baseUrl + mangaUrl). Он создаст промежуточный файл ./manga.json с информацией о манге.
2. Запустить meta-downloader он автоматически скачает все сканы страниц по ссылкам в папку ./manga/{chapterIndex}
3. На этом шаге можно уже читать мангу просто пролистывая изображения. Но можно воспользоваться веб ридером.
4. (опционально) Запустить create-web-reader он создаст файл ./manga/info.js нужный для веб ридера который одержит всю информацию о сканах и главах. Скопировать index.html в папку ./manga и открыть в браузере.
